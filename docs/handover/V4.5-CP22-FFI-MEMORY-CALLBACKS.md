# v4.5 CP22 — FFI memory, structs and callbacks

Added `ffi_buffer`, `ffi_bytes`, `ffi_sizeof`, `ffi_struct`, and `ffi_callback`.

Buffers are Nift-owned contiguous byte storage. `ffi_struct(layout, values)` uses native C size/alignment rules for the supported scalar fields and returns an addressable buffer; v4.5 deliberately does not pretend that arbitrary by-value aggregate calling is portable without a general ABI engine. Structs are therefore passed to C by pointer through the `buffer` signature type.

Callbacks are currently the certified `i64(i64)` shape. They synchronously enter the owning Parser on the thread performing `ffi_call`; unsupported callback shapes and nested callback activation are hard errors. A callback invoked from an unrelated foreign thread has no thread-local owner and is rejected/sentinel-returned rather than entering the interpreter concurrently.
