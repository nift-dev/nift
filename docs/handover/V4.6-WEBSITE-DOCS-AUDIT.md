## Changes made in this audit

**Release notes (`ReleaseNotes.md`, Nift repo):** the v4.6.0 section previously
listed only six items (timers, secure random, output streams, relative imports,
resource paths). Completed with the missing user-facing work: bytes + byte I/O +
FFI bridges; recoverable operational errors; structured diagnostics; filesystem
type-inspection primitives; exact-number semantics; stream insertion/extraction;
deterministic package graph; worker/concurrency hardening; C ABI 1.3. Commit
`6705e87`.

**Website source (`nift-dev.github.io`, stage branch — written, built and
verified locally; commit/publish pending approval):**

- Added `content/docs/runtime-bytes.html` — first-class immutable bytes
  (construction, operations, identity/sharing, text/JSON boundaries, byte I/O,
  FFI copying bridges).
- Added `content/docs/runtime-errors.html` — recoverable operational errors +
  structured diagnostics, with the recoverable/fatal distinction.
- Added `content/docs/runtime-utilities.html` — epoch/sleep/timer/
  secure_random_bytes + output streams.
- Updated `content/docs/scripting-filesystem.html` — added `is_file`, `is_dir`,
  `stat` to the primitive table.
- Registered the three new pages in `.nift/tracked.json` and added navigation
  cards in `content/docs.html`.
- Fixed stale current-version references: `C ABI 1.1` → `C ABI 1.3`
  (`runtime-embedding.html`, `scripting.html`, `docs.html`, `ai-context.txt`,
  `agents.md`); `The v4.5 FFI` → `The FFI` (`runtime-ffi.html`); `Nift v4.5 runs`
  → `Nift runs` (`runtime-concurrency.html`); `Nift 4.5` → `Nift`
  (`scripting.html`, `docs.html`); `Nift 4.5` / `4.5.0` → v4.6 in
  `developer-experience.html`, `llms.txt`, `agents.md`, `ai-context.txt`.
- Website build succeeds; the three new pages render (h1 + navigation + the
  filesystem primitives verified in the generated `public/` output).
