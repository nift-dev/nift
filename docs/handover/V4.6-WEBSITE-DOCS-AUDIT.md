## Independent review

An independent reviewer audited the source + rendered site + binary and found the
drift above (all fixed): stale C ABI 1.1 body text; the new bytes/errors/utilities
pages documenting non-existent APIs (`to_hex`/`from_hex`/`take`/`skip`/`contains`/
hex literals, `json.parse`); the missing sidebar registration; `nift path`; the
missing Packages group; obsolete `run`/`sh`; the `stat()` shape; embedding
examples using non-existent value methods; and stale `v4.5` FFI wording. It
confirmed no page describes post-v4.6 work (RuntimeValue campaign, map redesign,
Strut-backed HTTP) as shipped, and found no real broken internal links/anchors
(the flagged ones are code-example paths).
