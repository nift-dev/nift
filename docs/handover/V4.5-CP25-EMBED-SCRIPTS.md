# v4.5 CP25 — Embedded scripts and evaluation

`nift::Engine` now owns a lazy persistent script runtime. `execute()` runs a complete program and preserves its declarations for subsequent `evaluate()` calls; `evaluate()` returns a typed `nift::Value`. Script results are reported through `nift::ScriptResult` and never terminate the host process.

Embedded programs run in hosted mode rather than shell mode. Their source root/environment/platform come from the Engine; shell-only process-global mutations such as `cd` and `setenv` are not implicitly enabled. `cmd` and `args` are supplied explicitly to `execute()`, and `set_platform()` controls `platform()` independently of the host `os()`.

Operations on one Engine script runtime are serialized. Different Engine instances have independent parser state. The C ABI exposes execute/evaluate with JSON-preserving result transport, while C++ receives `nift::Value` directly.
