# Nift v4.2.0 Language Campaign

## Frozen contract

v4.2 separates template grammar from `@fn` program grammar.

| Template | Function body |
|---|---|
| `@if(...) {...}` | `if(...) {...}` |
| `@for(...) {...}` | `for(...) {...}` |
| `@while(...) {...}` | `while(...) {...}` |
| `$[x := expr]` | `x := expr` |
| `$[x = expr]` | `x = expr` |
| `$[foo(...)]` | `foo(...)` |
| `break`, `continue` in loops | `break`, `continue` in loops |
| bare `return` in fragments | `return [expr]` |

Function statements accept newline, `;`, and block close as boundaries. `@fn` may return a value or no value; no value is `null`. Fragments remain template grammar and may only use bare value-less `return`. `break` and `continue` target the innermost `@for`/`@while` in the current callable boundary and cannot escape a function/fragment call.

`null` is a first-class scalar. Equality/inequality with null are valid; ordering with null is an error.

`copy` is reserved for shallow copying and `deepcopy` for recursive copying in the struct tranche after CP14.
