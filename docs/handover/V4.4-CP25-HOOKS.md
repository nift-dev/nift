# CP25 project build hooks

`.nift/config.json` accepts string paths for `pre build`, `post build`, and mode-specific `pre/post build -all`, `--auto`, and `--repair` hooks. Mode-specific keys take precedence over the generic key and never double-run. Hook execution itself remains a DeepSeek completion item: it must run `.f` through the in-process parser, with project-pre before final affected-set calculation and project-post only after the build result is known.
