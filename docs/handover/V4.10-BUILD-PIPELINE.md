The public contract is [Build Scripts](../BUILD-SCRIPTS.md). New tracked fields
are `pre-build`, `build`, `post-build`, and completion-order `depends`. Explicit
scripts win over dotted sidecar discovery; deprecated pre/post sidecars remain
fallback, with ambiguity rejected. Custom builds own output bytes and bypass
normal render/minify. Every successful item commits metadata after post succeeds.
Native per-phase scopes and invocation-local environment overlays avoid changing
process-global cwd/environment. Legacy space-separated hooks retain their behavior.

The graph validates iteratively and schedules numeric adjacency/indegrees with a
condition-variable ready queue. Clean prerequisites participate without rendering;
ordinary generated file dependencies can invalidate clean consumers after their
prerequisites complete. `depends` alone never invalidates. Failure blocks transitive
descendants; other branches continue. Output cache identities cover symlink aliases,
and retired source owners keep concurrent readers alive until the next build epoch.
No-dependency projects bypass graph construction and its allocations.

Inside existing Nift projects, rewrite/redesign init only adds missing files,
including from nested invocation paths. It preserves config, tracking, workbooks,
README, AGENTS, HANDOVER, and every other existing file byte-for-byte. Existing
append/replace policy flags cannot weaken that rule. Fresh initialization keeps
its existing policies. Both modes coexist and reruns are idempotent.

First-party black-box contracts and an independent NRS module cover the new public
behavior. See [campaign evidence](../evidence/cp410-build-pipeline/report.md) for
certification, paired 10k baseline comparisons, graph shapes, and the complete
92-page documentation coverage audit.

C ABI remains 1.3; RuntimeValue layout and canonical/vendored Jsonic++ are unchanged.
Official benchmark evidence remains frozen. No release or package publication is
part of this tranche.
