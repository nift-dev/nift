# Nift v4.4 glob contract

- `*` matches zero or more characters within one path component.
- `?` matches exactly one character within one path component.
- `**` as a complete component matches zero or more directory levels.
- `\\` escapes wildcard characters in expression-string patterns. Command-land escaping is specified separately by the shell grammar.
- Wildcards do not match a leading `.` unless that component explicitly begins with `.`. Recursive `**` likewise does not descend hidden directories unless a later contract explicitly opts in.
- Recursive traversal does not follow directory symlinks, preventing cycles. A symlink can still be matched as a leaf.
- Results are unique and lexicographically ordered by normalized generic path for deterministic cross-platform behavior.
- `/` is the canonical pattern separator internally; platform paths are normalized before matching.
- Relative patterns resolve against the same base as the receiving filesystem operation; absolute patterns remain absolute.
- `ls` returns an empty array on no match. `remove` preserves its existing missing-path/no-op behavior. `copy`/`move` fail when expansion leaves no source.
- Globbing is filesystem-only by this contract. Structured-data wildcard behavior is a separate decision (CP8).
