# Nift v4.5 CP33 adversarial/sanitizer review

Date: 2026-09-27.

## Local results

`tests/v45_adversarial_runtime.sh` is a permanent bounded gate covering malformed FFI signatures/arity, use-after-close library handles, mutex wrong-owner unlock, thread/async error propagation, repeated native thread/async teardown, and shell background-job churn. It passes against the current candidate.

The CP33 build also cleaned misleading-indentation warnings in the v4.5 POSIX process/job-control paths that became visible during sanitizer compilation; focused background/job-control tests pass after the formatting-only repair.

## Sanitizer status

The maintained `make test-sanitize` ASan+UBSan+LSan build was attempted with the current source. Compilation reached the large runtime translation units but this container killed a compiler process while the overall command also approached the execution cap. Therefore **no full CP33 ASan/UBSan/LSan pass is claimed here**. The failure was a resource/tool-environment failure, not a reported sanitizer finding.

Earlier CP18 evidence remains valid: TSan passed the maintained thread/mutex/async suites and, after fixing the `localtime`/`gmtime` race, a parallel documentation build. CP33 does not upgrade that earlier evidence into a fresh complete TSan release wall.

Valgrind is not installed in this environment. macOS and Windows platform certification cannot be performed here. These are explicit Codex/hosted-CI gates.
