# v4.5 CP26 — Trusted host callables and host invocation

C++ embedding hosts may register `Engine::HostFunction` values with `register_function`. Nift resolves them as ordinary named callables after Nift-local functions, converts arguments/results through `nift::Value`, and converts host exceptions into script errors rather than allowing an exception to cross the interpreter boundary.

`Engine::call(name, args)` invokes a named Nift function in the persistent script runtime and returns a typed `ScriptResult`. This supports the full host → Nift → host nesting path: a host calls a Nift function, and that Nift function can call a registered host function.

Host functions are a trusted embedding seam and intentionally remain distinct from dynamic-library FFI. Registration is an Engine mutation and must not race active operations. A host callback must not recursively call methods on the same Engine while its operation lock is held; use a separate Engine/runtime for deliberately re-entrant host orchestration.
