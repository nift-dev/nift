# Nift v4.4 advanced shell evidence checkpoint

The v4.4 core deliberately stops at the high-value Bash-compatible command grammar already implemented: quoting/escaping, globs, pipelines, stdin/stdout/stderr redirection, `2>&1`, `&&`/`||`, environment assignments, PATH fallback and Nift-native command resolution.

Full interactive job control (`jobs`, `fg`, `bg`, terminal process groups/signals), aliases beyond ordinary Nift functions/`niftrc`, heredocs, subshell semantics and command-specific completion are **not yet justified enough to expand the v4.4 implementation surface**. A bare `&` now fails explicitly rather than silently behaving synchronously.

DeepSeek should revisit this after dogfooding `nift sh`, especially if agent workflows demonstrate a concrete need. Proper Unix job control and Windows parity need dedicated design/certification rather than a partial emulation.
