# v4.5 CP21 — Dynamic libraries and scalar calls

Implemented script builtins: `ffi_open(path)`, `ffi_call(lib, symbol, signature, ...)`, and `ffi_close(lib)`.

The built-in dispatcher supports integer/bool/pointer/C-string register-class calls up to six arguments and homogeneous `f32`/`f64` calls up to four arguments. Mixed floating/integer signatures, variadics, and non-native calling conventions are rejected rather than guessed. Returned C strings are copied immediately; returned pointers become opaque runtime-local handles.

ELF/macOS use `dlopen`/`dlsym`; Windows uses `LoadLibraryW`/`GetProcAddress`. CI remains the authority for non-Linux platform certification.
