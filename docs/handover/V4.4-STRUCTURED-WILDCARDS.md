# v4.4 structured wildcard decision

CP8 found one deliberately small expressive win: `object.pick([...])` and `object.omit([...])` accept the same `*`/`?` component matcher for object-key patterns, e.g. `obj.pick(["user_*"])`.

No wildcard semantics are added to structural navigation, array indexing, computed access, descendants/ancestors, or arbitrary JSON paths. Existing lambdas (`filter`, `map`, `find`, `has`, computed indexing) already compose clearly for those jobs, and adding `**`/path matching there would effectively create a second JSONPath-like language. Filesystem globs and object-key patterns therefore share a small matcher, not a broad query language.
