## Delivered Surface

- Internal structured diagnostics carry disposition, code, immutable origin,
  and typed propagation frames while preserving existing public result layouts.
- `RuntimeType::Error` is appended as ordinal 9. Error values are immutable,
  validate custom `user.*` codes and bounded cause chains, retain their first
  trusted throw origin, and support deterministic equality and fingerprints.
- Contextual `throw expr` and `try { ... } catch(name) { ... }` are implemented
  without reserving identifiers in declarations, call position, members, or
  compound assignments. Only Error values can be thrown. Fatal failures bypass
  catch.
- Prepared and legacy execution propagate recoverable outcomes through
  callables, methods, loops, imports, templates, scripts, REPL evaluation,
  futures, and threads. Repeated `await` and `join` replay the same Error.
- Failed worker-owning imports always become fatal
  `internal.import_lifecycle`. Their complete parser-owned graph remains alive
  until top-level worker finalization, after which deferred cleanup and
  parser-local identity rollback run.
- Error values are recursively rejected from successful public transport and
  rendering boundaries, including arrays, objects, parser collections and
  structs, interpolation, joins, files, streams, CLI eval, C++ Engine/Context,
  host callables, public Value conversion, C ABI, and maintained bindings.

## CP4 Entry Conditions

CP4 may convert only the filesystem, FileValue, stream, runtime JSON, and schema
validation operational failures explicitly approved in the registry. Keep
argument, type, mode, authority, policy, resource lifecycle, malformed schema,
and implementation failures fatal.

Before changing a producer:

1. Identify its code and disposition directly at the branch; never infer either
   from message text or prefixes.
2. Preserve retry and rollback behavior, especially failed FileValue saves and
   stream state.
3. Preserve the defining diagnostic origin and append frames at propagation
   boundaries rather than replacing it.
4. Add prepared/legacy parity and public-boundary tests for every converted
   family.
5. Re-run `make test-v46-b4-cp3` as the immutable Batch 4A regression baseline.

Do not broaden catchability to process results, host failures, package commands,
network/database APIs, native tools, syntax/type/arity/privacy/arithmetic/policy
failures, or any other CP5+ or explicitly deferred surface.
