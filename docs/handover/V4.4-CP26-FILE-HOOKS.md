# CP26 file build hooks

Tracked entries in `.nift/tracked.json` accept the same command-aware hook keys as project config. Hooks are stored per `TrackedInfo`. Execution must be limited to entries actually processed by the invocation and ordered project-pre -> file-pre -> render -> file-post -> project-post. Pre failures block rendering; post failures fail the build. In-process execution/context wiring remains explicitly queued for DeepSeek review/completion.
