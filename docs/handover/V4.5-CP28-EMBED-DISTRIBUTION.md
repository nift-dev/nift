# V4.5 CP28 — embedding distribution and binding conformance

## Contract

- C ABI additive version is **1.1** for the new script/eval result surface.
- `make embed` stages headers, static/shared libraries and `nift.pc` under `dist/embed-prefix`.
- C and C++ consumer tests compile and link only against the staged prefix.
- Go, Python, Node and C# wrappers track the v4.5 `execute`/`evaluate` API without reimplementing language semantics.
