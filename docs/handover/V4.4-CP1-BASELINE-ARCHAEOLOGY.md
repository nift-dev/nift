# v4.4 CP1 — baseline and archaeology

Baseline: v4.3.0 (`c727564`) is the released language baseline. v4.4 planning commits sit above it and do not alter runtime semantics.

## Old-Nift behavior inventory

The current repository history available in this workspace does not contain the pre-v4 shell implementation, so CP1 freezes the known historical product contract from maintained handovers and maintainer-confirmed behavior rather than pretending old source was inspected.

| Area | v4.4 decision |
|---|---|
| `nift sh` interactive shell | preserve, rewrite on the v4 parser/runtime |
| `niftrc` | preserve name/idea, redesign as ordinary modern Nift code |
| tab completion | preserve, rewrite; include PATH programs and filesystem paths |
| persistent history | preserve, rewrite |
| process/system execution | preserve capability, redesign around direct argv spawning rather than implicit shell strings |
| environment/cwd | preserve, redesign as explicit persistent shell state |
| project-wide pre/post build scripts | preserve, redesign as `.f` lifecycle hooks with structured context |
| per-file pre/post build scripts | preserve, redesign as `.f` lifecycle hooks with incremental correctness |
| filesystem commands/aliases | preserve and generalize (`ls`, `cp`, `mv`, `rm`, etc.) |
| command-style parsing | preserve concept, redesign with Bash-compatible command syntax plus explicit Nift expression syntax |
| old parser/evaluator quirks | reject; do not reproduce compatibility bugs merely because old Nift accepted them |

If an older source snapshot is supplied later, archaeology may add compatibility notes, but it must not reopen this baseline without a concrete user-visible reason.
