# CP20 R3 corrections (post-CP16 rebase)

**Base:** CP20 R2 `62fe31dc`, rebased onto CP16-certified runtime-2
`7f0ed468` (tree `b3036290`). R3 commits are local only.

## Findings

- **B0:** script job control restored. Foreground script commands consume job
  IDs and leave completed `jobs` entries; `bg`/`fg` send SIGCONT; stopped jobs
  are reported `Stopped`; `wait N`/dogfood behaviour matches pre-CP20.
  `test-v45-native-runtime` passes unchanged.
- **B1:** deferred exec reports carry their stage index. A dropped middle
  report cannot mark the wrong stage. Pending reports are drained under fd
  pressure, restoring runnable endpoints at low limits; a closed report read
  end no longer SIGPIPEs a failing stage (127).
- **B2:** the 10,000-group test compares against the pre-test count without an
  orphan sweep.
- **B3:** destruction keeps a pgid while any process, including an unreaped
  zombie, still has that pgrp; the orphan sweep then reaps it.
- **B4:** scripted fd-leak check added (delta 0), and a corresponding mx1
  mutant is detected; recorded stderr/status expectations cover the
  streaming/redirection fixtures.
- **B5:** output files are no longer pre-seeded; redirection/append assertions
  now observe the shell's effects.
- **B6:** Windows fixture includes console pipeline and redirection bytes;
  Makefile uses `$(PYTHON)` and 77-skip; CI snippet exports Python. Windows
  runtime evidence is still outstanding.
- **B7:** docs/report claims corrected; D-052 records the CP20 gate.

## D5 additions

- Host pipelines may need one extra launch descriptor per started stage
  (`exec_report_optional`); documented contract remains 3 stages at
  `ulimit -n 8`, 8 at `-n 10`, single capture at `-n 6`. Shell pipelines now
  run at `-n 7` after draining pending reports; scripting needs `-n 9`.
- `NIFT_CP20_FORCE_SCRIPTED` (POSIX) and `NIFT_CP20_FORCE_INTERACTIVE`
  (Windows) are test-only switches, read only in the shell capability path;
  they are to be removed/renamed in CP21.
- Bash +10% is missed/deferred (D-052), not passed.
