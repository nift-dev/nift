Implemented independent requirements
- VM-owned session selection precedes rc/initial-unit execution; D-054 refusal
  never switches engine, replays history or mirrors executable state in Parser.
- Stable binding/type Cells, private whole-unit compilation/publication,
  immutable source maps, original Error origins and surviving runtime effects.
- .niftrc, initial script/file/stdin/inline -> -i continuity, shell classification,
  interpolation and command routing retain the existing tested session path.
- Named functions, saved aliases, mutable closures/captures, aggregate COW,
  source/Program ownership, registry order and old/new struct versions persist.
- Dormant higher-order bodies stage using bounded owned pure call-result facts.
  Open results remain explicitly unproved and can stage only dormant untyped uses.
  Current targets/effects are inferred anew. Unknown current input has separate
  taint, including effect-only Any callees and partially known target sets. Every
  reachable historical-only call refuses before effects.
- Shared Cell/projection effects exchange full current callable facts within
  one inference instance; same-kind Function replacement cannot hide new returns
  or sibling mutations. AST callable IDs never persist between compilations.
- Unreached declarations can establish a new valid kind, schema and const
  contract. Mutable String/Function bindings preserve legacy tag compatibility.
- Array payloads and call/native/Error/constructor operand windows reserve
  contiguous destinations before evaluating scratch-producing session reads.
- Cold numeric diagnostics preserve enclosing return/lambda context, including
  argument calls, without changing ordinary CP13B reporting or caught Errors.
- Allocation failure before admission preserves the namespace; an admitted
  internal exception closes the damaged session. No legacy replay occurs.

Performance and memory
All performance observations are local, with individual samples/binary hashes;
no portable performance certification, threshold change or waiver is claimed.

Matched CP18 instruction references, 1,000,000 iterations:
                 ordinary catches      captured-Cell catches
 default         3,047,691,273           5,382,801,348
 switch          3,053,689,851           5,386,799,900
Relative to CP18: default +0.131653%, +0.410559%; switch +0.065802%, +0.167562%.
All four exceed their references. No instruction gate is declared passed and no
waiver is claimed. The previous +0.112% Cell obligation has not been resolved;
these final measurements show a larger outstanding regression. Earlier raw runs
are retained with their own binary hashes. This audit does not establish the
cause of the instruction differences; a compiler-only source change by itself
is not performance evidence. No broad optimization round was performed.

Matched-dispatch compiler timing samples and bootstrap intervals are preserved.
The final local medians were about 35.0 us (default) and 32.6 us (switch) for
related commands, 13.6/5.5 us for unrelated commands and 224/252 us for stateless
compilation. Matched baseline samples, individual medians, bootstrap intervals
and all raw counters are preserved. The run is noisy and does not establish
performance neutrality. Structural tests establish that stateless scripts
allocate no proof sets and unrelated commands leave existing proof sets intact;
these checks do not waive measured compiler or runtime costs.

10,000 related commands retained one fact (40 bytes of vector payload) and one
code unit. Allocator live bytes were 130,464 after 1,000 and 130,480 after 10,000;
the 16-byte difference coincides with a longer current source spelling; fact
and code-unit counts stay flat. This is allocator evidence, not a total
process-memory budget claim. Weak-owner tests separately establish reclamation.
